# Restitution de la participation à Vigie-Nature École

This set of functions and scripts allows to get participation information for Vigie-Nature École.

## How to use this scripts

### requirements

-    [Hackathon.vn](https://github.com/Vigie-Nature/hackathon.vn) for `download_from_ftp`
-    .env file

### run the script

> bilan_participation.R

Outputs :

- graph_participation classes
- graph participation profs
- graph participation observations
- graph participation etab
- graph participation eleves
- graph par protocoles
- graph fidelisation (années quantitatives)
- graph fidelisation (deux classes de participation)
